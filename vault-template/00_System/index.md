# Relationship intelligence vault

This is a blank operating scaffold. Add only notes you are permitted to keep.

## System registers

- [[source-register]] — source intake and provenance
- [[interaction-ledger]] — one row per strategic interaction
- [[stakeholder-interest-register]] — attributed interests and next assets
- [[content-index]] — navigation and maintained content map
- [[log]] — append-only maintenance chronology

## Working rule

Keep raw material separate from maintained synthesis. Every interaction,
interest, commitment, or recommendation should point back to a source and carry
an attribution state when the evidence is incomplete.
