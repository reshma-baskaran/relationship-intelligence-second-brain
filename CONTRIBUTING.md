# Contributing

Contributions that improve provenance, relationship memory or privacy safety
are welcome.

1. Open an issue describing the problem and expected outcome.
2. Preserve evidence context, relationship status, attribution, privacy and
   record mode on every affected artifact.
3. Do not add transcripts, contact data, credentials, private relationship
   history or fictional customer outcomes.
4. Add or update tests for behavior changes.
5. Run `python -m unittest discover -s tests -v` before opening a pull request.

Public statements must remain research-only. Simulation and test fixtures must
never enter production relationship metrics.
